# Brain plugin marketplace

Claude Code / Codex plugin for the Brain MCP knowledge base — work sessions,
context packs, search explanation, fact lineage, and agent-to-agent handoffs.

## Install

Claude Code:

```bash
claude plugin marketplace add levirge/brain
claude plugin install brain@brain
```

Codex CLI:

```bash
codex plugin add levirge/brain
```

Plugin details: [plugins/brain/README.md](plugins/brain/README.md).

Versioning mirrors the Brain server release (CalVer `YY.M.D`).
